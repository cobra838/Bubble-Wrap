Import settings

When ✂ Auto-split is ON, creates {{pageBreak}} instead of soft splits.
On import, changes bigEndian. If the selected value differs from the source value, swaps framesLo and framesHi in {{delay}} and {{autoAdvance}}. MSYT is treated as source bigEndian: true. Does not work with the BCML file format because one texts.json contains multiple source message files.
On import, forces whether attributes are present. false removes all imported attributes. Does not work with the BCML file format because one texts.json contains multiple source message files.
